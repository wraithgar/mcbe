# Durability Viewer

This is a behavior pack for [bedrock server](https://www.minecraft.net/en-us/download/server/bedrock) that adds durability numbers to durable items.

## Installation

- Copy the `durability_viewer/` directory and put it in the `world_behavior_packs/` folder of your server (you may need to create this)

- Restart or reload your server to load the new behavior pack.  You should see a line during initialization that looks something like this:

    ```Pack Stack - [00] GeorgeCo Durability Viewer (id: 07a47fe2-5d2b-4873-9f9d-6660fc2091ed, version: 1.0.0) @ behavior_packs/durability_viewer```
